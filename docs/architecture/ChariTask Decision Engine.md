# The ChariTask Decision Engine

## Purpose

The ChariTask Decision Engine is the intelligence layer of the platform.

It transforms Workspace Context into meaningful guidance, recommendations,
automation, and action.

The engine doesn't simply store context.

It understands it.

It reasons about it.

It helps people make better decisions.

---

# The Decision Cycle

Workspace Context

↓

Evaluate

↓

Prioritize

↓

Recommend

↓

Guide

↓

Act

↓

Learn

↓

Workspace Context Updates

---

# The Engine Decides

• What matters now

• What should happen next

• Which workspace should be active

• Which module should handle the task

• Which information is relevant

• What needs attention

• What can be automated safely

• What should be communicated

• How actions align with organizational goals

---

# The Engine Produces

• Prioritized task lists

• Workspace insights

• AI Mentor conversations

• Recommendations

• Context summaries

• Automation triggers

• Decision explanations

---

# Design Principle

Every important recommendation
should be explainable.

The engine should always be able to answer:

"Why?"
