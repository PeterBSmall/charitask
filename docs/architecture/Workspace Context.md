# Workspace Context

## Purpose

Workspace Context represents everything the ChariTask Decision Engine needs
to understand before making a decision.

It is not a database.

It is not a screen.

It is a living representation of a person's current operating environment.

The Workspace Context continuously evolves as people work, projects change,
tasks are completed, and organizational priorities shift.

# Design Principle

The richer the Workspace Context,
the better the decisions.

The goal is not to collect more data.

The goal is to understand what matters.
